# Textures réelles de gravats

Échantillons découpés dans des **photos aériennes réelles du séisme de Turquie (février 2023)**, publiées dans le **domaine public** sur Wikimedia Commons (photos du gouvernement des États-Unis). Aucune image ne provient de RescueNet ni d'un autre jeu de données d'entraînement.

| Échantillon | Photo source (dossier `sources/`) |
|---|---|
| `gravats_1.png`, `gravats_2.png` | `h8.jpg` |
| `gravats_3.png` | `h2.jpg` |
| `gravats_4.png` | `h10.jpg` |

Les liens Wikimedia de chaque photo sont dans `sources/sources.txt` (`h<n>.jpg` = ligne n).

Seules les zones de gravats éclairées ont été gardées, sans ombre portée ni objet identifiable. L'échelle des photos sources est estimée à environ 16 px/m dans ces versions de 1920 px de large. C'est une approximation, car les vues sont un peu obliques.
